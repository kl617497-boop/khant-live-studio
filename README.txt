KhantAi LIVE Studio - prototype v0.1
Created by Khant

1. Extract this ZIP.
2. Run a local HTTP server in this folder, e.g. Python: python -m http.server 8000
3. Open http://localhost:8000 in your browser.
4. Click Open Overlay, keep both tabs open in the same browser and origin, then Send Test Gift.
5. To use on a phone, deploy these files to an HTTPS host. PWA installation availability depends on browser and deployment setup.

IMPORTANT: This is a functional OFFLINE TEST-GIFT PROTOTYPE, not a TikTok LIVE integration.
No actual TikTok connection, real gift ingestion, authentication, payment processing, or secure licensing is implemented.
The demo uses BroadcastChannel; overlay and dashboard should be open in the same browser origin.
